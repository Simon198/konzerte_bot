# Changelog Version 0.3 (2026-10-20)
- Added band images and genres, and switched audio samples to Deezer

# New Features
1. Event messages now show the band's image as a small sticker
2. Bands now have a genre list (taken from their newest album), shown as "Genre: ..." in the message
3. The "Hörprobe" button now opens the band's top track on Deezer instead of a YouTube video
4. Band information (image, genres and audio sample) is looked up with a single Deezer search per band
5. Bands with no upcoming event are removed automatically, together with their image

# Removed
1. Removed the YouTube audio-sample lookup (replaced by Deezer)
