# Changelog Version 0.4 (2026-10-22)
- Added genre filtering, a "Tickets" button linking to the original event page, and reversible interest on events

# New Features
1. Added the /genres command to block music genres you don't want to receive
2. Blocked genres are marked with an X and can be toggled back on at any time
3. Newly added genres are automatically delivered to everyone (only blocked genres are stored)
4. Event messages now include a "Tickets" button that opens the original event page on the venue's website
5. You can now change your mind about your interest in an event: after "Interesse" the button becomes "Interesse zurücknehmen", and after "Kein Interesse" an "Interesse" button remains so you can still reverse the decision
6. The /next command now shows an "Interesse zurücknehmen" button on each listed event so you can remove interest directly
